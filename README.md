## 🚀 Project Overview

EduPulse is a web-based learning platform that allows students to share knowledge and follow structured learning plans. It fosters collaborative learning through interactive media posts, real-time engagement, and community-driven content.

The platform supports:
- Skill sharing through posts (with image/video support)
- Personal learning plans with milestone tracking
- Social features like likes, comments, and followers
- Secure login via OAuth 2.0

---

## 🌐 Tech Stack

- **Frontend:** React.js  
- **Backend:** Java Spring Boot  
- **Authentication:** OAuth 2.0  
- **Database:** MongoDB 
- **Hosting:** Not specified

---

## ✅ Functional Features

### 🧠 Skill Sharing Post
- Create posts with up to 3 images or 30-sec videos and descriptions
- Edit/Delete posts
- Tagging and profile display for each post
- Link posts to progress milestones

### 📚 Learning Plan
- Create/Update/Delete structured learning plans
- Track progress with visual logs
- Share plans publicly or keep them private

### 💬 Social Interaction
- Like/Unlike posts
- Add/Edit/Delete comments
- @Mentions in comment threads
- Real-time notifications

### 👤 User Profiles
- Public profiles with bio, photo, and contact info
- View user posts and activity
- Follow/Unfollow users
- User search by name/username

---

## 🔐 REST API Features

- CRUD for posts and learning plans
- OAuth 2.0 based user authentication
- Role-based access control (RBAC)
- Real-time notifications (WebSocket/polling)
- Search and filtering capabilities
- HTTPS & JWT security
